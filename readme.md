# GitHub Profile Explorer 🔍

Aplicação front-end que permite buscar perfis públicos do GitHub e visualizar informações relevantes de forma simples, rápida e visualmente profissional.

## 🚀 Deploy
git-hub-profile-explorer-five.vercel.app

## 🖥️ Preview
Interface limpa, moderna e responsiva, com animações sutis e foco em experiência do usuário.

## ✨ Funcionalidades
- Buscar usuários do GitHub pelo username
- Exibição de avatar, nome e bio
- Visualização de seguidores e número de repositórios
- Lista de repositórios em destaque
- Feedback visual de loading
- Tratamento de erro para usuários inexistentes
- Animações suaves na renderização dos dados

## 🛠️ Tecnologias utilizadas
- HTML5 semântico
- CSS3 (Flexbox, variáveis e animações)
- JavaScript (ES6+)
- GitHub REST API
- Deploy com Vercel

## 🎯 Objetivo do projeto
Demonstrar domínio de:
- Consumo de APIs externas
- Manipulação do DOM
- Organização de código front-end
- Criação de interfaces modernas e funcionais
- Boas práticas de UX/UI
